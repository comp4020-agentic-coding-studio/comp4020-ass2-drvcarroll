Gaining initial access is a distinct engineering problem from what happens
afterward, and it is typically the operator's highest-risk moment. This
session surveys how that first entry is actually achieved.

## Before the session

No new material needs to be brought forward. Lab 4 supplies its own
prepared evidence for each scenario.

## In the session

The lecture covers the principal vector families: social engineering,
technical exploitation, physical media, network exposure and supply-chain
compromise, together with the case-study method used to determine after the
fact which vector was responsible. Lab 4 then provides prepared evidence for
five simulated scenarios (phishing, a software vulnerability, removable
media, a network attack and a supply-chain compromise) and asks students to
identify and compare the vector each one relies on.

## Afterwards

Students should be able to state which vector left the greatest number of
artefacts and which required the least interaction from the target.
Persistence, the question of remaining inside an environment once entry has
been gained, is the following week's subject.
